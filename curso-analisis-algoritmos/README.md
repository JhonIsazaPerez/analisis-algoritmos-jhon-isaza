# Análisis de Algoritmos

## Descripción del repositorio

Este repositorio reúne material de estudio, ejercicios y laboratorios del curso de análisis de algoritmos. Está organizado para facilitar la práctica, la documentación y la comparación de soluciones entre conceptos teóricos y ejercicios aplicados.

## Estructura de carpetas

- `benchmarks/`: contiene benchmarks y mediciones de rendimiento para comparar algoritmos y evaluar su eficiencia.
- `ejercicios-clase/`: incluye ejercicios desarrollados durante las sesiones de clase para reforzar conceptos vistos en teoría.
- `laboratorios/`: almacena actividades más extensas y proyectos de práctica donde se aplican técnicas de análisis y optimización.

## Objetivo del curso

El propósito principal del repositorio es aprender a evaluar el comportamiento de los algoritmos en términos de complejidad temporal y espacial, así como a desarrollar soluciones eficientes y bien documentadas.
